# 別の宇宙のあなた

過去の「人生の選択(IF)」を入力すると、選ばなかった道の先で暮らすもうひとりの自分の情景を、統計シミュレーションで描き出すWebアプリです。

## 構成

- Next.js (App Router, TypeScript) / Tailwind CSS v4 / Framer Motion
- AI は使いません。人生は日本の統計的な傾向にもとづくシミュレーションで、端末(ブラウザ)内で計算します。サーバー処理も外部APIもないので、何度遊んでも費用はかかりません。
- 入力画面は、木の枝が分かれて伸びていく選択(`components/TreeWizard.tsx`)です。選ぶたびに、枝が斜め上へランダムに伸びます。
- 年齢は10歳から90歳まで。18歳未満は、学歴・仕事・結婚などを聞かず(学生で、実家で暮らす前提)、ターニングポイントは「子どもの頃」(3歳以降)から選びます。
- 流れ: ①「いまのあなた」を選択式で入力(年齢・出生地・性別・先天性の持病・MBTI任意・学歴・仕事・住まい・家族) → ②「分岐させたいところ」を選ぶ(進路/仕事/住む場所/家族+その年齢+選ばなかった道) → ③その年齢から人生を再スタートし、1年ずつ時間が流れる。節目で選択イベントが出る(用意した選択肢か、手入力) → ④亡くなるまで進み、⑤分岐しなかった今のままのあなたの一生と見比べる。
- 時間の進み: 等倍で1年=12秒(100歳まで生きて20分)。一時停止、×2・×4・×8 の倍速あり。`components/PlayScreen.tsx` の `BASE_MS` で変えられます。
- 職業は、厚生労働省「賃金構造基本統計調査の新職種区分案(職種一覧)」の11大分類と、その下の職種名にもとづきます(`lib/sim/data/jp-jobs.ts`)。職種→勤め先(大企業・中堅・中小・非正規・公務員・自営)まで選び、資格が必要な職種は、頭の良さに応じた合格率が出ます。
- 出来事: 選択を求めないもの(風邪で寝込んだ、いじめ、事故、昇格・降格、リストラ、友人や家族の出来事など。毎年たいてい1つ以上)と、選択を求めるもの(不倫・裁判・ペット・留学・早期退職・転勤など)(`lib/sim/data/jp-events.ts`)。子どもの誕生・ペットを迎えたときは、名前をつけられます。親の死や、子どもの節目も年表に出ます。
- 海外: 移住すると、現在地(国・都市)、収入・物価の水準、出来事、文章が、その国のものになる。帰国もできる(`lib/sim/data/jp-countries.ts`)。
- 習い事: 大人も子どもも、いつでも始める・やめる。同時に5つまで(`jp-lessons.ts`、`LessonPanel.tsx`)。18歳未満は、お小遣い(円)で、増減が出る。
- 昼と夜: ヘッダーのボタンで切り替え。夜は窓の灯り・赤いランプ・月(`Ambient.tsx`)。
- 恋人・配偶者・子ども(男子・女子は50%ずつ)の名前は、乱数で作る。
- 借金: 貯金が足りなくても、警告のうえで、家族・友人・銀行・カードローン・闇金から借りて使える。借りると、経済は底に落ち、幸福度・つながりが下がる。毎年、利息がつき、返せないと督促・自己破産・取り立てが起こる(`jp-debt.ts`)。災厄で貯金を超える出費が出ても、足りない分は借金になる。
- 幸福度: 0に近づくとうつ状態になり、深刻な病気とともに死期を早めます。そのとき、自分を救う選択の場面が出ます。
- 空模様: 2〜3年ごとに晴れ・曇り・雨・雪・雷が移り変わり(晴れは5割以上)、背景も変わります(`lib/sim/weather.ts`)。
- 毎年の文章: 土地の特徴・季節と空模様・気持ち・仕事・家族やペット・年齢から、年ごとに違う組み合わせで作ります(`lib/sim/data/jp-vignette.ts`)。
- 選択は枝分かれします(進路→大学の種類→専攻、仕事→働き方や勤め先、住まい→物件の種類 など)。各選択肢の下に、いまの地域・年齢・景気に応じた給料や費用の目安が出ます。`lib/sim/data/jp-turning.ts`。
- 給料・景気: `lib/sim/salary.ts`(職業×年齢×地域×性別×学歴×専攻×雇用形態×企業規模×景気)と `lib/sim/economy.ts`(年齢ごとの景気の指数。不況では就職・転職が難しくなり、失職もある)。
- 資産: 貯金は最初から見えますが、株は「資産の使い方」から本人が始めたときだけ表示されます(始めない人生もある)。使い道を自分の言葉で書いて貯金を使うこともできます。 貯金(手取りから生活費を引いた黒字の一部が毎年たまる)を、架空の株価(日本株インデックス・個別の成長株・債券/預金)で自由に売買できます。株価は月ごとに動き、12か月で1歳。価格は分岐した/しなかった二つの人生で共通です。`lib/sim/market.ts` / `AssetPanel.tsx`。
- 運の分け方: 景気・空模様・株価の乱数は「種+年齢+種類」で決まるので、二つの人生で同じです。一方、死亡(事故・急病・災害などの突然の死と、病気などの死)の乱数は、人生ごとに別で、同じ年に亡くなるのは偶然(約3%)です。死因も記録します。平均の寿命は、公表値に合わせて較正しています(`mortalityScale`)。
- 手入力: 文章の意味は読み取れません。キーワードで「挑戦・安定・学び・つながり・休む」の候補を出し、本人が近い方向を選んで能力値に反映します。文章は年表にそのまま残ります。
- 世界版への拡張: 国ごとのデータは `CountryData`(`lib/sim/types.ts`)として `lib/sim/data/` に置きます。日本版は `jp.ts`(数値表)、`jp-turning.ts`(分岐と選択イベント)、`jp-scene.ts`(情景の文章)。
- ログインは任意: ログインしなくても使えます。Google ログイン(Firebase Auth)をすると、保存した平行世界を Firestore のアカウント配下に保存します。未ログイン時はブラウザの LocalStorage に保存します。パスワードやメールアドレスはこのアプリでは保存しません。

## 起動

```bash
npm install
npm run dev   # http://localhost:3000
npm run build
```

何も設定しなくても動きます。ログイン機能を使う場合は `.env.example` を `.env.local` にコピーして Firebase の値を入れてください(Firestore ルールは `firestore.rules`)。

## ページ

- `/` 遊ぶ / `/concept` コンセプト / `/sources` データについて / `/privacy` プライバシー / `/contact` お問い合わせ
- `/archive` みんなの人生(サンプル+公開された人生) / `/archive/[id]` 個別ページ。公開は、ログインした本人が保存時に選んだときだけ(持病・MBTI・自由記述・細かい地名は除く)。取り下げも本人が可能。
- お問い合わせは Firebase の `contacts` に保存(読めるのは運営のみ)。Firebase 未設定なら、`NEXT_PUBLIC_CONTACT_EMAIL` のメールを開く。どちらも未設定なら「準備中」と表示。
- `firestore.rules` に、保存・公開・お問い合わせのルールがあります。

## メモ

- `lib/sim/data/jp.ts` の数値は、日本の公的統計で一般に知られる傾向を概算で表にしたものです(公式値の転記ではありません)。生命表・人口動態統計・賃金構造基本統計調査などの実データに置き換える想定です。
- 分岐や選択イベントの効果(`jp-turning.ts` の増減値)は統計ではなく、設計上の仮定です。MBTI の影響はごく小さな演出にとどめています。
- 統計は「いまの数字」が最後まで続くものとして計算します。
- 「カードとして画像化する」は、比較結果を1枚のPNG画像(`lib/card.ts`、ブラウザ内で生成)にして保存します。
- 死亡率だけは公的統計に合わせています: 厚生労働省「令和5年簡易生命表」の平均余命(男81.09年・女87.14年ほか)に合うよう当てはめ、シミュレーションの平均死亡年齢が公表値とほぼ一致することを確認済みです。結婚・出産・賃金などは今のところ概算です。
