# 別の宇宙のあなた

過去の「人生の選択(もしも)」を入力すると、選ばなかった道の先を生きるもうひとりの自分を、統計にもとづくシミュレーションで見届けられるWebアプリです。ブラウザの中だけで動き、サーバー処理も外部APIも使いません。

## 特徴

- **選択式の入力**: 年齢・出生地・性別・学歴・仕事・住まい・家族などを選び、「分岐させたい場面」(進路・仕事・住む場所・家族)と、選ばなかった道を決めます。入力画面は、枝が分かれて伸びる形です(`components/TreeWizard.tsx`)。
- **一年ずつ進む人生**: 等倍で1年が12秒です。一時停止と×2・×4・×8の倍速があります。節目では選択イベントが出ます。選択肢は、用意したものか手入力です。
- **公的統計にもとづく数値**: 平均寿命・賃金・景気・進学率などを使います。職業は、厚生労働省の職種区分にもとづきます(`lib/sim/data/jp-jobs.ts`)。
- **お金の動き**: 税金・生活費・ローン・借金・投資を扱います。株価は完全に架空です。
- **出来事と毎年の文章**: 病気・事故・転職・結婚・子育て・海外移住などが起こり、土地・季節・年齢・気持ちから、毎年の文章を組み立てます。
- **昼・夕・夜の背景**: 街・空・天気・星・月が移り変わります(`components/Ambient.tsx`)。
- **ログインは任意**: Googleログイン(Firebase Auth)をすると、保存した人生をFirestoreに置けます。ログインしないときは、ブラウザのLocalStorageに保存します。

## 設計の要点

- **乱数は種から決まります**(`lib/sim/rng.ts`)。同じ種からは、同じ展開を再現できます。
- **シミュレーションと表示を分けています**。計算は `lib/sim/`(`engine.ts`・`salary.ts`・`economy.ts`・`market.ts` など)、国ごとのデータは `lib/sim/data/` に置きます。別の国のデータを足せる形です(`CountryData`、`lib/sim/types.ts`)。
- **静的サイトとして書き出します**(`output: "export"`)。ホスティングは静的ファイルを置けるところなら動きます。
- 背景の街は、SVGを実行時に組み立てて画像として描いています。見えていない層は動きを止めて、負荷を抑えています。

## 技術構成

Next.js 16(App Router)・React 19・TypeScript・Tailwind CSS v4・Framer Motion・Firebase(任意)

## ディレクトリ

| パス | 内容 |
| --- | --- |
| `app/` | ページ(トップ・コンセプト・データの出典・プライバシー・アーカイブなど) |
| `components/` | 画面の部品(入力画面・プレイ画面・背景・結果) |
| `lib/sim/` | シミュレーション本体と、その国ごとのデータ |
| `locales/` | 画面の文言 |
| `docs/` | 設計メモ(`BRANCHES.md` は、分岐と条件の一覧) |

## 起動

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # 静的ファイルを out/ に書き出す
npm run typecheck
```

何も設定しなくても動きます。ログインなどを使う場合は、`.env.example` を `.env.local` にコピーして値を入れてください。Firestoreのルールは `firestore.rules` です。

## データについて

賃金・寿命・景気・進学率などの出典は、サイト内の「データについて」のページにまとめています。結果は統計をもとにしたゲームで、占いや予測ではありません。

## 開発について

このプロジェクトは、AIコーディングアシスタント(Claude Code)の支援を受けて開発しています。何を作るか、仕様の決定、画面と文章の確認や修正の指示、公開の判断は、作者が行っています。コミット履歴には、AIとの共同作業を示す `Co-Authored-By` の記載が残っています。

テストは未整備です。動作の確認は、主に手元での実行とブラウザの表示で行っています。
