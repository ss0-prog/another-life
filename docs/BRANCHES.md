# 条件分岐の一覧

このサイトの選択肢・出来事・分岐の条件を、プログラムから自動で書き出したものです。**条件の欄は、実際のコードの式をそのまま載せています**(p = その人。p.age は年齢、p.stats.money は経済力、p.married は結婚しているか、など)。
確率や金額は、設計上の仮定です。気になる箇所があれば、見出しの ID を教えてください。

## 1. 最初の入力(ウィザード)の分岐
- 10〜17歳: 年齢 → 生まれた場所 → 性別 → 先天性の持病 → 現在の持病 → MBTI → 住んでいる地域 → 分岐点(学歴・仕事・結婚・資産は聞かない。学生・実家・未婚として扱う)
- 18歳以上: 上に加えて「いま学校に通っていますか?」(通っていない/高校/専門学校/大学/大学院)
  - 在学中 → 卒業まであと何年か → 住まい → 結婚(している場合は子ども) → 資産
  - 通っていない → 最終学歴 → いまの仕事(大分類)→(働いていれば)具体的な職種 → 勤め先 → 住まい → 結婚(している場合は子ども) → 資産
- 最後に分岐点: 種類(その年齢で選べるものだけ)→ 分岐した年齢 → 選ばなかった道(今の自分がすでに選んだ道は出ない)

- 運転・輸送の仕事(id: transport) / 今の自分がこれなら除外: `s.occ === occ`

### 住む場所(place) — 15歳より後から選べる
- 東京23区で暮らす(id: tokyo) / 今の自分がこれなら除外: `s.region === r`
- 大阪・名古屋・福岡などの大都市で暮らす(id: metro) / 今の自分がこれなら除外: `s.region === r`
- 地方都市で暮らす(id: local) / 今の自分がこれなら除外: `s.region === r`
- 郊外・農村部で暮らす(id: rural) / 今の自分がこれなら除外: `s.region === r`
- 海外で暮らす(id: abroad) / 今の自分がこれなら除外: `false`

### 家族(family) — 20歳より後から選べる
- 結婚する(id: married) / 今の自分がこれなら除外: `s.married`
- ひとりで生きていく(id: single) / 今の自分がこれなら除外: `!s.married`
- 子どもを持つ(id: child) / 今の自分がこれなら除外: `s.kids > 0`
- 子どもを持たない(id: childfree) / 今の自分がこれなら除外: `s.kids === 0 && s.married`
